# Portfolio de Laura Llavador

Versión con el estilo visual actualizado y Joyería Suárez como primer ejemplo del caso de Kimera.

## Qué contiene

La web completa en HTML, CSS y JavaScript, con imágenes, tipografías locales, CV y el vídeo 3D de NextPort. Es una web estática: no necesita instalar dependencias ni compilarse.

## Subir a GitHub

1. Descomprime este ZIP en tu ordenador.
2. Sube los archivos y carpetas descomprimidos a tu repositorio. El archivo index.html debe quedar en la raíz del proyecto.
3. Conserva la carpeta asset y el resto de archivos con sus nombres y estructura.

## Publicar en tu VPS

Obtén o actualiza este repositorio en el VPS. Configura el servidor web de tu dominio para servir la carpeta que contiene index.html como directorio público. Los archivos pueden servirse directamente, sin ejecutar un proceso de Node.js.

La portada es index.html. Los proyectos son kimera.html, nextport.html, compressflow.html y comida.html. Los enlaces internos ya utilizan estas rutas .html. Si quieres acceder también mediante rutas sin extensión, como /kimera, configura esa equivalencia en tu servidor web.

Las fuentes incluyen sus licencias en asset/fonts.
